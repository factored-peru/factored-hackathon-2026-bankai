# Módulos

- `backend`: Cloud Run, cuenta de servicio y secretos de la API Bun.
- `frontend`: Firebase App Hosting y configuración pública mínima.
- `pipeline`: Cloud Run Job y permisos de ejecución Python.
- `data`: GCS, BigQuery y políticas de lifecycle.
- `state`: Firestore y Memorystore for Valkey.
- `network`: conectividad privada, egress y reglas de acceso.
- `observability`: logs, métricas, alertas y datasets saneados.
